# data/

`parsed_pages.json` — namunaviy kiruvchi ma'lumot: "1937–1938-yillardagi «Katta qirg'in» tarixining muhim sanalari" (ma'lumotnoma, Toshkent, 2013) PDF idan sahifa-sahifa ajratib olingan matn (40 sahifa).

Matn PDF dan avtomatik olingani uchun OCR xatolari uchrashi mumkin. O'z hujjatlaringiz bilan ishlash uchun:

```bash
python -m rag parse sizning_fayl.pdf
python -m rag build
```

> Manba hujjatning mualliflik huquqi o'z egalariga tegishli. Ushbu fayl faqat demo uchun; o'z repongizda ommaga ochishdan oldin ruxsat holatini tekshiring.
